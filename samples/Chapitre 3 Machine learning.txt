Machine Learning: Modèle
• On peut voir le modèle comme une fonction notée f qui prend un échantillon en
entrée, et qui renvoie une décision. Données

Où :

x : l’espace des entrées (caractéristiques),
y : l’espace des sorties (valeurs à prédire, classes, etc.),
f : la fonction cible que le modèle doit apprendre à approximer à partir des
données.
• La détermination de f est le cœur d’un problème de Machine Learning.
• Celle-ci se passe en deux étapes :
Choix d’une fonction.
Détermination des paramètres de la fonction à l’aide des échantillons.
Cette phase s’appelle entraînement ou apprentissage du modèle.

L’apprentissage non supervisé
• Réduction de dimensionnalité
• Le principe:
• Réduire la complexité du dataset en projetant les données dans un espace de plus
petite dimension (c’est-à-dire avec moins de variables))

• Objectif:
• Accélérer l’apprentissage de la machine
• Lutter contre le fléau de la dimension, un phénomène qui augmente le risque
d’overfitting lorsqu’il y a trop de variables (ou dimensions).
• Le "fléau de la dimension", c’est quand il y a trop de variables, ce qui perturbe l’apprentissage de l’IA et
augmente le risque d’erreurs.
21

L’apprentissage non supervisé
• Réduction de dimensionnalité
 Les données multivariées comprennent souvent un grand nombre de variables ou de caractéristiques. Cela peut avoir une
incidence sur le run time et les besoins en mémoire. Les techniques de réduction de la dimensionnalité réduisent le
nombre de caractéristiques (dimensions) tout en conservant les informations nécessaires des données d'origine.

 On cherche donc à simplifier les données pour les rendre :
 plus faciles à visualiser,
 plus rapides à traiter,
 moins bruitées (moins de redondance)

Les étapes d’un projet Machine Learning
• Un projet de Machine Learning suit un ensemble d’étapes méthodiques
permettant de passer d’un besoin métier à une solution opérationnelle.
• Ces étapes forment un cycle, car un modèle ML doit être continuellement
amélioré selon les données et les retours utilisateurs.
Définition du problème
Collecte et préparation des données
Exploration des données (EDA)
Séparation des données
Choix du modèle
Entraînement du modèle
Évaluation et optimisation
Déploiement et suivi
28

Les étapes d’un projet Machine Learning
• Définition du problème
La première étape d’un projet en Machine Learning. Elle consiste à
comprendre le besoin réel, à définir le cadre de travail et à choisir la
bonne approche algorithmique.
Identifier l'objectif métier, déterminer si c'est un problème
d'apprentissage supervisé (classification, régression) ou nonsupervisé.

29

Les étapes d’un projet Machine Learning
• Collecte et préparation des données
Les données sont la base de tout projet en Machine Learning.
• Sources possibles :
Bases de données internes (SQL, NoSQL)
APIs externes (météo, finance, réseaux sociaux…)
Fichiers plats : CSV, Excel, JSON
Capteurs / IoT (température, mouvement, sons…)
Logs d’applications (clickstream, journaux systèmes)
Web scraping (données extraites de sites web)
Open Data (Kaggle, UCI Machine Learning Repository, data.gov…
• Rassembler les données pertinentes et les nettoyer (gestion des valeurs manquantes,
des erreurs et des incohérences).
30

Les étapes d’un projet Machine Learning
• Exploration des données (EDA)
Une étape essentielle dans tout projet Data Science ou Machine Learning. Elle permet de
comprendre les données avant de construire un modèle. et souvent, un bon EDA = 50% du
travail.
Comprendre la structure des données
Types de variables (numériques, catégorielles, textuelles, images)
Taille et volume du dataset (nombre de lignes, colonnes)
Statistiques descriptives (moyenne, médiane, min/max, quartiles)
Identifier les données manquantes
Colonnes avec beaucoup de valeurs nulles
Stratégies pour les gérer :
 Suppression
 Imputation (moyenne, médiane, modèle)

Diviser les données en ensembles d'entraînement (pour entraîner le

Les étapes d’un projet Machine Learning
• Choix du modèle
Le choix du modèle est une étape essentielle dans un projet de Machine
Learning.
Le modèle à utiliser dépend du type de problème, de la forme des
données, de la complexité, et des objectifs du projet (rapidité,
interprétation, précision…).
Exemples :
• Régression : Linear Regression, Random Forest, XGBoost…
• Classification : Logistic Regression, SVM, KNN, …
• Clustering : K-Means, DBSCAN, PCA…
33

Les étapes d’un projet Machine Learning
• Entraînement du modèle
L’entraînement est l’étape où le modèle apprend à partir des données.
On lui fournit les exemples d’entraînement (X_train, y_train), et il ajuste ses paramètres (poids,
coefficients, arbres, etc.) pour minimiser l’erreur.
Choisir une fonction de perte (loss function)
La loss function, ou fonction de perte, est une formule mathématique qui mesure l’erreur d’un
modèle de machine learning :
elle compare la prédiction du modèle avec la valeur réelle,
Ajuster les hyperparamètres (learning rate, nombre d’arbres…)
Le learning rate est un hyperparamètre qui contrôle la vitesse d’apprentissage du modèle.
Dans les modèles enensemble (Random Forest, Gradient Boosting), le nombre d’arbres détermine
combien d’arbres seront construits.
Utiliser une méthode d’optimisation(gradient descent, RMSprop…)
