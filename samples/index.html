Définitions Clés — À connaître parfaitement

⚠️ La prof demande souvent : "Définissez les éléments suivants : IA, ML, DL" et "Expliquez la relation entre IA, ML, DL et IA générative". Ces définitions doivent être précises et hiérarchisées.
Intelligence
L'intelligence est liée à l'être humain, à travers ses facultés de compréhension et d'apprentissage, et elle est observable grâce à son comportement.
Intelligence = Compréhension + Apprentissage Elle englobe : capacité d'adaptation, de penser, d'assimiler des connaissances, de comprendre des relations, d'évaluation et de jugement.
Intelligence Artificielle (IA)
Ensemble des techniques mises en œuvre afin de construire des machines capables de faire preuve d'un comportement que l'on peut qualifier d'intelligent. C'est une imitation de l'intelligence humaine — pas une vraie intelligence.

Artificiel = Machine + Logiciel
Machine Learning (ML)
Sous-domaine de l'IA qui donne à une machine la capacité d'apprendre sans être explicitement programmée. Il consiste à développer et entraîner un modèle mathématique à partir d'un ensemble de données d'apprentissage afin qu'il puisse généraliser et effectuer des prédictions sur de nouvelles données.
Deep Learning (DL)
Sous-domaine du Machine Learning reposant sur des réseaux de neurones artificiels multicouches (inspirés du cerveau humain). Il permet de résoudre des problèmes complexes à partir de grandes quantités de données non-structurées (images, texte, son). Il réalise automatiquement l'extraction de caractéristiques (contrairement au ML classique qui la fait manuellement).

Relation hiérarchique IA → ML → DL → IA Générative

IA (ensemble de techniques imitant l'intelligence humaine)
↓ inclut
Machine Learning (apprend à partir de données sans prog. explicite)
↓ inclut
Deep Learning (réseaux de neurones profonds pour données complexes)
↓ application
IA Générative (modèles capables de générer texte, images, code — ex: ChatGPT, DALL-E)

Niveaux d'IA

IA Faible (Étroite)
  • Type le plus répandu aujourd'hui
  • Se concentre sur une tâche ou un domaine spécifique
  • Très performante dans son domaine mais ne peut pas généraliser
  • Exemples : Siri, Alexa, reconnaissance faciale, algorithmes de recommandation, chatbots, détection de maladies
IA Forte (Générale)
  • Hypothétique, n'existe pas encore
  • Capable d'accomplir n'importe quelle tâche intellectuelle humaine
  • Apprendre, raisonner, résoudre des problèmes complexes, s'adapter
  • Domaine de recherche actif
IA Super-intelligente
  • Dépasserait les capacités humaines dans tous les domaines
  • Hypothèse futuriste
  • Explorée en science-fiction et recherche prospective

Les 3 éléments nécessaires au fonctionnement d'un système d'IA

① Les Données

Nourrissent et entraînent les algorithmes. La qualité des données est critique — des données biaisées produisent des modèles inefficaces.

② Les Algorithmes

Permettent d'atteindre l'objectif grâce à des règles et des modèles. C'est le "cerveau" de l'IA.

③ La Puissance de Calcul

Pour traiter les données et exécuter les algorithmes. Détermine la taille du modèle, la vitesse d'entraînement et de prédiction.

03

Prétraitement des Données — Détail Complet

📌 La prof insiste : "Le Machine Learning repose sur des opérations mathématiques. Les données doivent donc être converties en valeurs numériques pour être traitées."

Le prétraitement est l'ensemble des opérations qui visent à convertir les données primaires en un format exploitable pour le machine learning. Il protège aussi contre le surapprentissage.

① Imputation — Gestion des valeurs manquantes

Définition
Remplir les valeurs manquantes avec des mesures statistiques (moyenne, médiane) ou supprimer les lignes concernées. Les données manquantes faussent l'analyse et conduisent à des modèles inexacts.

Méthode 1 : Compléter par la moyenne

data.fillna(data['age'].mean()) # Remplace toutes les valeurs nulles de 'age' par la moyenne

Méthode 2 : Supprimer les lignes avec valeurs manquantes

data.dropna(axis=0) # Supprime toutes les lignes ayant au moins une valeur nulle

② Encodage — Conversion catégoriel → numérique

Pourquoi encoder ?
Le Machine Learning repose sur des opérations mathématiques. Il ne comprend que des données numériques. Les variables catégorielles (ex: "Normal"/"Suspect", "Homme"/"Femme") doivent être converties en valeurs numériques avant l'apprentissage.
Label Encoding

Remplace chaque catégorie par un entier.

Normal → 0 Suspect → 1

Utilisé pour variables binaires ou ordinales.

One-Hot Encoding

Crée une colonne binaire pour chaque catégorie.

Paiement en ligne → [1, 0, 0] ATM → [0, 1, 0] Virement → [0, 0, 1]

Utilisé pour variables nominales sans ordre.

③ Feature Engineering — Ingénierie des Caractéristiques

Objectif
Créer ou sélectionner les variables les plus pertinentes à partir des données existantes, afin d'améliorer les performances du modèle. Comprend deux sous-étapes : l'Extraction et la Sélection.
Feature Extraction (Extraction)

Générer de nouvelles variables à partir des informations cachées dans le jeu de données. Elle peut être faite :

  • Globalement (sur tout le dataset)
  • Localement (par zones)
  • De façon hybride
  • Exemple : transformer une date en "jour de la semaine"
  • Exemple : calculer l'IMC à partir du poids et de la taille
  • Dans DL : la feature extraction est automatique
  • Dans ML classique : elle est manuelle (via des descripteurs)
Feature Selection (Sélection)

Sélectionner les variables les plus utiles pour le modèle. Trop de variables = performances dégradées.

  • Technique : Variance Threshold
  • Technique : SelectKBest
  • Technique : SelectFromModel
  • Exemple : sur un dataset médical avec 100 variables, ne garder que l'âge, les symptômes, les antécédents — éliminer la "couleur préférée"

④ Normalisation — Mise à l'échelle

Principe
Ramener toutes les valeurs numériques à la même échelle, souvent entre 0 et 1. Cela évite qu'une variable avec de grandes valeurs domine les autres lors de l'entraînement.
x_normalisé = (x - x_min) / (x_max - x_min)
Algorithmes sensibles à la mise à l'échelle (à mémoriser)
  • K-Nearest Neighbors (KNN)
  • SVM (Support Vector Machines)
  • Régression Logistique
  • Réseaux de neurones (Deep Learning)
  • Méthodes basées sur les distances
  • PCA (réduction de dim.)
💡 Les arbres de décision (Decision Trees), Random Forest et les algorithmes basés sur des règles ne sont pas sensibles à la mise à l'échelle.

Types d'Apprentissage — Différences Clés

🎯 Questions fréquentes : "Quelle est la différence entre l'apprentissage supervisé et non supervisé ?", "Quelle est la différence entre la régression et la classification ?", "Quel type d'apprentissage pour ce problème ?"
Apprentissage Supervisé (Supervised Learning)

Définition : Le paradigme le plus populaire en ML. La machine reçoit des données étiquetées (X et Y). Elle apprend à prédire Y en fonction de X. On supervise l'apprentissage en montrant à la machine des exemples avec les bonnes réponses.

Régression

La sortie Y est une variable continue (numérique).

  • Prédire le prix d'un appartement
  • Prédire le montant des ventes
  • Prédire la consommation électrique
  • Algorithmes : Régression Linéaire, Random Forest, XGBoost
  • Métriques : MAE, MSE
Classification

La sortie Y est une variable catégorielle (discrète).

  • Email spam / non-spam
  • Transaction frauduleuse / normale
  • Accord ou refus d'un crédit
  • Tumeur maligne ou bénigne
  • Algorithmes : SVM, KNN, Régression Logistique, Random Forest
  • Métriques : Accuracy, Précision, Recall
Apprentissage Non Supervisé (Unsupervised Learning)

Définition : L'algorithme analyse des données brutes, non étiquetées (seulement X, sans Y). Il découvre par lui-même des structures, groupes ou motifs cachés. La machine cherche les points communs pour former des groupes.

Clustering (Regroupement)
  • Regrouper les données selon leur ressemblance
  • Segmentation de clients
  • Détection d'anomalies sans label
  • Filtrage automatique d'emails
  • Algorithmes : K-Means, DBSCAN, Agglomerative, GMM, Mean Shift, Spectral
Réduction de Dimensionnalité
  • Réduire le nombre de caractéristiques
  • Conserver l'information utile, éliminer la redondance
  • Accélère l'apprentissage
  • Évite l'overfitting (fléau de la dimension)
  • Algorithmes : PCA, ICA, LDA, KPCA, Isomap, MDS
Règles d'Association
  • Identifier des relations entre variables
  • Données transactionnelles
  • Articles souvent achetés ensemble
  • Exemple : panier d'achat (Market Basket Analysis)
Apprentissage Semi-supervisé

Définition : Mélange de données étiquetées (peu) + données non étiquetées (beaucoup). Utilisé quand les labels sont coûteux à obtenir.

  • Applications : classification d'images quand les labels sont coûteux, détection de comportements anormaux, analyse forestière avec peu de données terrain
Apprentissage par Renforcement

Définition : Un agent apprend en interagissant avec un environnement, en recevant des récompenses pour les bonnes actions et des pénalités pour les mauvaises.

  • Applications : jeux vidéo, robotique, voitures autonomes, trading
  • Algorithmes : Q-Learning, Deep Q-Network (DQN), Proximal Policy Optimization (PPO)

Les 8 Étapes d'un Projet Machine Learning

🎯 Question fréquente : "Décrivez les principales étapes d'un projet ML pour construire un modèle de détection de transactions suspectes." Ces 8 étapes doivent être connues avec leur contenu.
1
Définition du Problème

Comprendre le besoin réel, définir le cadre de travail, identifier l'objectif métier. Déterminer le type d'apprentissage (supervisé ? classification ou régression ? ou non supervisé ?). Exemple : prédire si une transaction est normale ou suspecte → classification binaire supervisée.

2
Collecte et Préparation des Données

Rassembler les données pertinentes depuis bases SQL, APIs, fichiers CSV, Kaggle, web scraping, logs... Nettoyer les données : gérer les valeurs manquantes (imputation ou suppression), encoder les variables catégorielles, normaliser les variables numériques.

3
Exploration des Données (EDA — Exploratory Data Analysis)

Analyser la structure, les types de variables, les statistiques descriptives (moyenne, médiane, min/max). Identifier les valeurs manquantes. Visualiser la distribution des données avec Matplotlib/Seaborn. Un bon EDA = 50% du travail. Il peut orienter le choix du modèle.

4
Séparation des Données (Train / Test Split)

Diviser le dataset en ensemble d'entraînement (80%) et ensemble de test (20%). On peut aussi avoir un ensemble de validation. Utiliser train_test_split de Scikit-learn. Le paramètre random_state fixe la division pour la reproductibilité.

5
Choix du Modèle (Algorithme)

Dépend du type de problème, de la forme des données, de la complexité, des objectifs. Régression → Régression Linéaire, Random Forest, XGBoost. Classification → SVM, KNN, Régression Logistique, Random Forest. Clustering → K-Means, DBSCAN.

6
Entraînement du Modèle

Le modèle apprend à partir de X_train et Y_train via la fonction fit(). Il ajuste ses paramètres (poids, coefficients) pour minimiser la fonction de perte (loss function). La loss function compare la prédiction du modèle avec la valeur réelle.

7
Évaluation et Optimisation

Tester le modèle sur X_test, comparer Y_prédit avec Y_test réel. Métriques de classification : accuracy, précision, recall, F1-score, matrice de confusion. Métriques de régression : MAE, MSE, RMSE. Ajuster les hyperparamètres si nécessaire (ex: nombre d'arbres dans Random Forest, valeur de K dans KNN).

8
Déploiement et Suivi

Rendre le modèle accessible à des utilisateurs, à une application ou à un système (déploiement en production). Surveiller ses performances et le mettre à jour régulièrement avec de nouvelles données si nécessaire.

07

Overfitting & Underfitting — Les ennemis du ML

🎯 Question fréquente : "Un modèle donne : Train = 98% et Test = 60%. Identifiez le problème et proposez une solution." — La prof donne cet exemple exact dans ses examens.
Overfitting (Surapprentissage)

Définition : Le modèle mémorise les données d'entraînement au lieu d'apprendre les patterns généraux.

Signe : Performances train très élevées + performances test faibles.

Train = 98% | Test = 60% → OVERFITTING

Le modèle ne peut pas être utilisé sur de nouvelles données !

Solutions :

  • Ajouter plus de données d'entraînement
  • Réduire la complexité du modèle
  • Utiliser la réduction de dimensionnalité
  • Utiliser la régularisation (L1, L2)
  • Utiliser la cross-validation
  • Dropout (pour les réseaux de neurones)
Underfitting (Sous-apprentissage)

Définition : Le modèle n'arrive pas à s'adapter aux données d'apprentissage. Il est trop simple.

Signe : Mauvaises performances sur les données d'entraînement ET de test.

Train = 55% | Test = 50% → UNDERFITTING

Solutions :

  • Augmenter la complexité du modèle
  • Ajouter de nouvelles features
  • Réduire la régularisation
  • Entraîner plus longtemps
Bon Modèle (Idéal)

Définition : Performances proches entre train et test. Le modèle généralise bien.

Train = 90% | Test = 88% → IDÉAL ✓

Les valeurs ne doivent pas être égales, mais très proches. Une grande différence = problème.

Technique K-Fold Cross-Validation :
L'ensemble de données est divisé en k ensembles de tailles presque égales. On entraîne k fois en changeant l'ensemble de validation. Cela améliore la fiabilité de l'évaluation.

Matrice de Confusion — Erreur Type I et Type II

La Matrice de Confusion

Prédit : PositifPrédit : Négatif
Réel : Positif VP (True Positive)
Bonne prédiction positive		 FN (False Negative)
Erreur de Type II
Réel : Négatif FP (False Positive)
Erreur de Type I		 VN (True Negative)
Bonne prédiction négative

Erreur Type I vs Erreur Type II

Erreur de Type I = False Positive (FP)
La prédiction est POSITIVE alors que la valeur réelle est NÉGATIVE.
Exemple : Le modèle dit "fraude" mais la transaction est normale.
Erreur de Type II = False Negative (FN)
La prédiction est NÉGATIVE alors que la valeur réelle est POSITIVE.
Exemple : Le modèle dit "normale" mais la transaction est frauduleuse.

Métriques d'évaluation

Classification
Accuracy = (VP + VN) / (VP + VN + FP + FN)
Précision = VP / (VP + FP)
Recall = VP / (VP + FN)

Recall = Sensibilité. Important quand les faux négatifs sont critiques (ex: cancer, fraude).

Régression
MAE = moyenne |y_réel - y_prédit|
MSE = moyenne (y_réel - y_prédit)²
RMSE = √MSE

MAE = Mean Absolute Error. MSE = Mean Squared Error. RMSE pénalise plus les grandes erreurs.

Python — Fonctions, Bibliothèques & Seaborn vs Matplotlib

Seaborn vs Matplotlib — Question fréquente

Matplotlib
  • Bibliothèque de visualisation de base en Python
  • Permet de créer des graphiques variés : histogrammes, courbes, scatter plots, barplots...
  • Plus de code nécessaire pour un résultat esthétique
  • Import : import matplotlib.pyplot as plt
  • Usage : plt.scatter(x, y), plt.show()
Seaborn
  • Extension de Matplotlib, plus puissante et plus esthétique par défaut
  • Spécialisée pour les graphiques statistiques
  • Graphiques relationnels entre variables, distributions, heatmaps facilement
  • Permet d'automatiser la création de graphiques → travail plus rapide
  • Import : import seaborn as sns

Question d'examen

Citez trois éléments nécessaires au fonctionnement d'un système d'IA.

Réponse

3. La puissance de calcul : nécessaire pour traiter les données et exécuter les algorithmes (GPU pour le Deep Learning).
Question d'examen

Quel est l'objectif de l'ingénierie des caractéristiques (feature engineering) ?

Réponse
L'ingénierie des caractéristiques vise à créer ou sélectionner les variables les plus pertinentes à partir des données existantes, afin d'améliorer les performances du modèle de Machine Learning. Elle comprend deux sous-étapes :
— L'extraction : générer de nouvelles variables à partir d'informations cachées (ex: transformer une date en jour de semaine, calculer l'IMC à partir du poids et de la taille).
— La sélection : ne garder que les variables les plus utiles pour éviter de dégrader le modèle avec trop de variables.
Question d'examen

Quelle est la différence entre Feature Selection et Feature Extraction ?

Réponse
Feature Extraction consiste à créer de nouvelles variables à partir des informations cachées dans les données. On transforme des données existantes pour en extraire de l'information utile (ex: extraire les contours d'une image, transformer une date en "jour de la semaine").

Feature Selection consiste à choisir les variables existantes les plus pertinentes parmi toutes les variables disponibles, en éliminant celles qui n'apportent pas de valeur au modèle. Trop de variables nuit aux performances.
Question d'examen

Expliquez le principe de la normalisation. Pourquoi l'utiliser ?

Réponse
La normalisation consiste à ramener toutes les valeurs numériques à la même échelle, généralement entre 0 et 1, à l'aide de la formule : x_normalisé = (x - x_min) / (x_max - x_min).

On l'utilise parce que certains algorithmes de Machine Learning sont sensibles à l'échelle des variables (KNN, SVM, régression logistique, réseaux de neurones). Sans normalisation, une variable avec de grandes valeurs (ex: salaire en DH) dominerait une variable avec de petites valeurs (ex: âge en années) et biaiserait le modèle.
Question d'examen

Quelle est la différence entre Seaborn et Matplotlib ?

Réponse
Matplotlib est la bibliothèque de visualisation de base en Python, permettant de créer des graphiques variés (histogrammes, courbes, scatter plots). Elle nécessite plus de code pour obtenir un résultat esthétique.

Seaborn est une extension de Matplotlib, plus puissante et plus esthétique par défaut. Elle est spécialisée dans les graphiques statistiques et permet de tracer facilement des graphiques relationnels entre variables, des distributions, des heatmaps. Elle permet aussi d'automatiser la création de graphiques pour travailler plus rapidement.
Question d'examen

Un modèle donne : Train = 98% et Test = 60%. Identifiez le problème et proposez une solution.

Réponse
Problème identifié : Overfitting (Surapprentissage)
Le modèle a mémorisé les données d'entraînement au lieu d'apprendre les patterns généraux. Il donne d'excellentes performances sur les données d'entraînement (98%) mais très mauvaises sur les données de test (60%), ce qui indique qu'il ne peut pas généraliser sur de nouvelles données.

Solutions proposées :
— Ajouter plus de données d'entraînement
— Réduire la complexité du modèle (simplifier l'architecture)
— Utiliser la régularisation (L1 ou L2)
— Utiliser la validation croisée (K-Fold Cross-Validation)
— Utiliser la réduction de dimensionnalité pour éliminer les variables redondantes
Question d'examen

Dans la matrice de confusion, expliquez la différence entre l'erreur de type I et l'erreur de type II.

Réponse
Erreur de Type I (False Positive — FP) : Le modèle prédit un résultat positif alors que la valeur réelle est négative. Exemple : le modèle dit qu'une transaction est "frauduleuse" alors qu'elle est normale.

Erreur de Type II (False Negative — FN) : Le modèle prédit un résultat négatif alors que la valeur réelle est positive. Exemple : le modèle dit qu'une transaction est "normale" alors qu'elle est frauduleuse.

Dans le secteur financier, l'erreur de Type II est généralement plus grave car elle permet à une vraie fraude de passer inaperçue.
Question d'examen — Cas pratique (type exercice 3)

Pour un dataset de transactions bancaires (colonnes : ID, Numéro de compte, Type de transaction, Statut, Montant, Classe [Normal/Suspect]) :

1. Avant la modélisation, quelle étape doit-on appliquer ? 2. Quelle opération pour la colonne "Classe" ? 3. Type d'apprentissage ? 4. Algorithme adapté ? 5. Étapes ML complètes.

Réponse complète
1. Étape à appliquer : Prétraitement des données (vérification des valeurs manquantes, encodage des variables catégorielles, normalisation des variables numériques, sélection de caractéristiques pertinentes).

2. Colonne "Classe" : Encodage (Label Encoding) : Normal → 0, Suspect → 1. Obligatoire car le ML ne traite que des valeurs numériques.

3. Type d'apprentissage : Apprentissage supervisé (car les données sont étiquetées — la colonne "Classe" fournit le label). La tâche est une classification binaire (deux classes : Normal ou Suspect).

4. Algorithme adapté : SVM (efficace pour classification binaire) ou Random Forest (robuste pour données tabulaires avec variables mixtes).

5. Étapes ML : (1) Définir le problème → classification binaire supervisée. (2) Préparer les données → gérer valeurs manquantes, encoder Type/Statut/Localisation/Classe, normaliser Montant. (3) EDA → visualiser la distribution des montants, détecter le déséquilibre des classes. (4) Séparation → 80% train / 20% test. (5) Choisir l'algo → SVM ou Random Forest. (6) Entraîner → model.fit(X_train, Y_train). (7) Évaluer → accuracy, précision, recall sur X_test. (8) Déployer → intégrer au système bancaire.

Question d'examen

Expliquez pourquoi on procède à l'encodage des variables catégorielles.

Réponse
On encode les variables catégorielles parce que le Machine Learning repose sur des opérations mathématiques. Les algorithmes ne peuvent traiter que des valeurs numériques. Les données catégorielles (ex: "Normal", "Suspect", "Homme", "Femme") doivent donc être converties en valeurs numériques (0, 1, 2...) avant d'être fournies au modèle pour l'entraînement.
